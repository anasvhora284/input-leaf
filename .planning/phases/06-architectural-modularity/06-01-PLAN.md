# Plan 06-01: Architectural Modularity & Pure Domain Coordination

<objective>
Decouple connection state transitions, generation validation, retry backoff calculation, keepalive miss tracking, and input routing logic out of the Android `ConnectionService` shell into a pure JVM-testable `ConnectionCoordinator`, and implement IPv6-safe versioned server record codec in `AppPreferences` (#12, ARCH-01, ARCH-02):
1. Extract `ConnectionCoordinator` with zero Android framework dependencies to govern connection generations, state transitions, retry delay calculations, keepalive timeouts, screen bounds clamping, and input event gating.
2. Provide 100% deterministic JVM test coverage for `ConnectionCoordinator` without Android Context, Mockito mocks, or Robolectric.
3. Implement `ServerRecordCodec` with canonical `v2|<base64url-server>|<base64url-value>` format and backwards-compatible legacy migration to prevent IPv6 literal address truncation in DataStore.
4. Refactor `ConnectionService` into an Android lifecycle and side-effect shell delegating domain decisions to `ConnectionCoordinator`.
5. Strictly adhere to zero emojis across all code, tests, and documentation (ARCH-02).
</objective>

<context>
Issue #12 (reported by collaborator Guaje) identifies that `ConnectionService.kt` combines Android Service lifecycle and side effects (notifications, WindowMetrics, overlay services, IME switching, injector binder dispatch) with domain logic (connection generation counters, retry backoff calculation, keepalive miss counting, relative mouse delta clamping, and event routing). This makes coordination and edge-case testing unnecessarily coupled to Android framework lifecycle.
Additionally, server-keyed preference records for TLS fingerprints and transport modes stored as `server:value` suffer from IPv6 ambiguity where `2001:db8::1` splits on the first colon, truncating the server address to `2001`.
</context>

         * Tracks `userInitiatedDisconnect: Boolean`, `infoAckPending: Boolean`, `pointerOnScreen: Boolean`.
         * Tracks `mouseEnabled: Boolean`, `keyboardEnabled: Boolean`, `absolutePointer: Boolean`.
         * Tracks screen boundaries (`screenWidth: Int`, `screenHeight: Int`) and coordinates (`currentMouseX: Float`, `currentMouseY: Float`).

         * `onConnectRejected(generation: Int): Boolean`: validates generation, transitions to Disconnected, returns true.
         * `onConnectFailed(reason: ConnectResult.FailureReason, detail: String?, policy: ConnectionTransportPolicy, generation: Int): ConnectFailureAction`: validates generation, transitions to Disconnected, evaluates `policy.shouldRetry(reason)`, calculates backoff retry or terminal failure.
         * `processEvent(event: InputLeapEvent, generation: Int, policy: ConnectionTransportPolicy): CoordinatorEventResult`:
           - Validates generation; returns `Ignored` if mismatch.
           - `Enter`: sets `pointerOnScreen = true`, transitions to `Active`, resets keepalive miss, returns `Enter(x, y)`.
           - `Leave`: returns `Leave`.
           - `onLeaveDebounceExpired(generation: Int): Boolean`: validates generation, sets `pointerOnScreen = false`, transitions to `Idle`, returns true.
           - `KeepAlive`: resets keepalive miss, returns `KeepAlive`.
           - `InfoAck`: sets `infoAckPending = false`, returns `InfoAck`.
           - `QueryInfo`: returns `QueryInfo(screenWidth, screenHeight, currentMouseX.toInt(), currentMouseY.toInt())`.
           - `MouseMoveAbs`: drops if `!mouseEnabled || infoAckPending`; clamps x and y to `[0f, screenWidth.toFloat()]` and `[0f, screenHeight.toFloat()]`; updates current position; returns `MouseMotion`.
           - `MouseMoveRel`: drops if `!mouseEnabled || infoAckPending`; adds dx and dy clamped to bounds; updates current position; returns `MouseMotion`.
           - `MouseDown`, `MouseUp`, `MouseWheel`: drops if `!mouseEnabled`; returns `Input(event)`.
           - `KeyDown`, `KeyUp`, `KeyRepeat`: drops if `!keyboardEnabled`; returns `Input(event)`.
           - `Unhandled("__DISCONNECTED__")`: drops if mismatch or userInitiatedDisconnect; resets pointerOnScreen; transitions to Disconnected; returns `Disconnected` with retry plan if retryable.
         * `onKeepAliveMiss(generation: Int): Boolean`: validates generation, increments miss count, transitions to Disconnected if `>= 4` and returns true.
         * `updateScreenBounds(width: Int, height: Int): ScreenBoundsUpdatePlan`: updates dimensions, clamps cursor coordinates, sets `infoAckPending = true` if connected, returns `SendDinf` if connected else `None`.
         * `disconnect(): Int`: sets userInitiatedDisconnect, increments generation, transitions to Disconnected, returns new generation.

         * Stale generation callbacks (ok, failed, rejected, event) are ignored.
         * `processEvent` Enter transitions to Active, Leave debounce transitions to Idle.
         * Input gating: mouse disabled drops motion and buttons; keyboard disabled drops keys; infoAckPending drops motion.
         * Relative and absolute mouse motion coordinate clamping to screen boundaries.
         * Screen resize/rotation triggers DINF and clamps existing cursor position when connected.
         * Disconnect on socket error triggers retry with backoff according to `RetryDelayCalculator`.
         * Disconnect when `userInitiatedDisconnect` suppresses retry.
         * Keepalive miss triggers timeout disconnection on the 4th miss.

       - Expose `stateFlow` from `coordinator.state`.
       - In `connect()` / `performConnect()`:
         * Obtain plan via `coordinator.startConnect(...)`.
         * Handle `ConnectResult.Ok`: invoke `coordinator.onConnectOk(...)`, save transport, start event loop and keepalive monitor, auto-switch IME.
         * Handle `ConnectResult.RejectedByUser`: invoke `coordinator.onConnectRejected(...)`, close connection, notify callback.
         * Handle `ConnectResult.Failed`: invoke `coordinator.onConnectFailed(...)`. If retry plan returned, call `scheduleRetry(serverIp, screenName, plan.delayMs, plan.generation)`.
       - In `startEventLoop`:
         * Pass incoming events to `val result = coordinator.processEvent(event, generation, activePolicy)`.
         * Handle `result`:
           - `is CoordinatorEventResult.Enter`: cancel leave debounce, update injector pointer speed, `onHidMouseEnter`, attach HID devices, `applyCursorOverlay()`.
           - `is CoordinatorEventResult.Leave`: `onHidMouseLeave()`, `scheduleLeave(generation)`.
           - `is CoordinatorEventResult.KeepAlive`: send keepalive via connection.
           - `is CoordinatorEventResult.InfoAck`: no-op (coordinator cleared infoAckPending).
           - `is CoordinatorEventResult.QueryInfo`: `connection?.sendDataInfo(result.width, result.height, result.x, result.y)`.
           - `is CoordinatorEventResult.MouseMotion`: `updateCursorPosition(result.cursorX, result.cursorY)`, `dispatchInput(result.event)`.
           - `is CoordinatorEventResult.Input`: `dispatchInput(result.event)`.
           - `is CoordinatorEventResult.Disconnected`: cancel leave debounce, hide cursor, detach HID devices, restore IME, schedule retry if `result.retry != null`.
           - `CoordinatorEventResult.Ignored`: drop event.
       - In `startKeepAliveMonitor`:
         * In loop: `if (coordinator.onKeepAliveMiss(generation)) { ... close connection, cleanup, break }`.
       - In `scheduleLeave`:
         * After delay: `if (coordinator.onLeaveDebounceExpired(generation)) { detach physical keyboard, scheduleHidMouseIdleDetach(generation) }`.
